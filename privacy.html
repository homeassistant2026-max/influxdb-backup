Privacy Policy - InfluxDB Backup

Last updated: September 27, 2026

About this application

InfluxDB Backup is a private, non-commercial backup configuration used by its owner to store copies of a personal InfluxDB database in Google Drive. It uses rclone and the Google Drive API. It is not offered as a public service.

Google Drive access

The application requests Google Drive access to upload, list, verify and manage the account owner's backup files. The configured Google Drive permission may allow access to other files in the authorized Google Drive account.

Data handling

Backup files may contain measurements and other data stored in the owner's InfluxDB database. These files are transferred from the owner's private server to the owner's Google Drive account.

OAuth credentials are stored locally on the owner's server to enable automated backups. This application does not operate a public website that collects visitor information.

Data sharing

The application owner does not sell Google user data. Backup data is not intentionally shared with other users through this application. Google processes data according to its applicable privacy terms.

Access and deletion

The account owner can delete backup files from Google Drive and revoke the application's access through Google Account security settings.
